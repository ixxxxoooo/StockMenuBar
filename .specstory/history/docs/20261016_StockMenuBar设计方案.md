# StockMenuBar 设计方案

> @author ixxxxoooo

## 1. 需求概述

原生 macOS A 股盘面监控应用:菜单栏常驻、Popover 快速浏览、主面板深度查看、悬浮迷你窗随时监控。技术栈 Swift 6 + SwiftUI + AppKit + Swift Charts + SwiftData,零第三方依赖。要求行情接口高可用。

## 2. 架构

```
数据源(腾讯/新浪/东财) → ProviderRouter(actor) → QuoteStore(单一数据源)
                                                    ├─ 菜单栏 NSStatusItem
                                                    ├─ Popover
                                                    ├─ 主面板
                                                    └─ 悬浮迷你窗
RefreshScheduler(交易时段/电源状态) 驱动 QuoteStore 批量轮询
```

- 所有界面共享同一个批量轮询结果,请求量与界面数量无关。
- `QuoteTicker` 为每只股票的独立可观察对象,行情更新只刷新对应行。

## 3. 高可用策略

1. 能力过滤:按请求类型(报价/分时/搜索)选择支持的数据源。
2. 健康排序:`latency × (1 + 5 × failureRate)`(EWMA)。
3. 熔断:连续失败 3 次熔断 30 秒,之后半开探测。
4. 对冲请求:主源 1.2 秒未返回则并行请求次源,先成功者胜出。
5. 数据校验:`prevClose > 0`,异常数据视为失败。
6. 全熔断兜底:所有数据源熔断时仍然尝试请求(fail-open)。

## 4. 智能刷新

| 时段 | 行为 |
| --- | --- |
| 9:15–11:30、13:00–15:05 | 按用户间隔(3/5/10 秒)轮询 |
| 午休 | 每 1 分钟 |
| 盘后/休市 | 不轮询,打开界面时单次请求 |
| 睡眠/锁屏/屏保/全部隐藏 | 暂停 |
| 低电量/高热 | 间隔翻倍 |

## 5. 悬浮迷你窗

- `NSPanel` + `.nonactivatingPanel`,层级 `.floating`,跨空间、可覆盖全屏应用。
- 三种形态:胶囊、迷你列表、卡片;背景透明度可调。
- 边缘吸附、位置记忆、鼠标移出淡化、穿透锁定。
- 快捷键:⌥⌘F 显示/隐藏,⌥⌘L 穿透锁定,⌥⌘H 老板键。

## 6. 持久化

SwiftData(`GroupEntity`/`ItemEntity`,级联删除)保存分组与自选;`Preferences` 基于 UserDefaults 保存刷新间隔、红绿反转、固定标的、悬浮窗配置等。无云端账号。
