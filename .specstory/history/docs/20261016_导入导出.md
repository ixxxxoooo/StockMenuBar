# 导入 / 导出(备份与迁移)

@author ixxxxoooo

## 需求
在设置中增加「导出」把已添加的自选分组与偏好导出,增加「导入」在另一台机器恢复,便于换机迁移。

## 方案
- 格式:带 `format` 与 `schemaVersion` 的 JSON,条目只存 `symbol`(如 `sh600519`、`fu113.cum`)与名称,分组与条目顺序即数组顺序。
- 导入模式:合并(同名分组追加缺失条目,重复导入幂等)/ 替换(先清空)。偏好设置可选择是否导入。
- 安全:解析阶段统一校验——体积上限 5MB、`format` 不匹配拒绝、`schemaVersion` 高于当前拒绝、证券代码经 `StockSymbol(full:)` 校验、数量与名称长度上限、设置越界值丢弃。
- 不包含:窗口位置、开机自启、更新状态。
