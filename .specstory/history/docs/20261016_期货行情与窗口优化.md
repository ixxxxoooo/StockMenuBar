# 期货行情与窗口体验优化

> @author ixxxxoooo

## 需求

1. 主面板侧栏展开/收起时卡顿闪烁。
2. 悬浮迷你窗无法拖动。
3. 需要应用图标。
4. 主面板打开时 Dock 显示图标(可切换窗口),关闭后仅留在菜单栏。
5. 增加期货行情:铜、煤,以及"东京"相关品种。

## 方案与结论

### 侧栏卡顿
根因是 `.searchable(placement: .sidebar)` 与 `.toolbar` 放在侧栏上,折叠时系统要把这些工具栏项在侧栏与标题栏之间迁移并重新布局。
改为:过滤框与「添加自选/管理分组」按钮直接放进侧栏(`safeAreaInset`),并将 `NSHostingController.sizingOptions` 置空,窗口尺寸完全由 `NSWindow` 管理。
实测录屏逐帧分析:折叠/展开约 5–6 帧,帧间差异单峰平滑,无突变帧。

### 悬浮窗拖动
SwiftUI 承载视图没有声明 `mouseDownCanMoveWindow`,`isMovableByWindowBackground` 不生效。
在 `FloatingPanel.sendEvent` 中自行计算位移:按下记录偏移,拖动超过 3pt 视为拖动并移动窗口;拖动结束吞掉抬起事件,避免误触发点击;点击、右键菜单、悬停仍交给 SwiftUI。实测拖动后位置保存并在重启后恢复。

### 应用图标
`Tools/GenerateIcon.swift` 用 CoreGraphics 绘制(深靛蓝渐变底 + 红涨绿跌 K 线 + 发光趋势线),一次导出 10 个尺寸写入 `AppIcon.appiconset`。需要调整样式时修改脚本重新运行即可。

### Dock 行为
主面板 `show` → `setActivationPolicy(.regular)`;窗口关闭/隐藏(老板键)→ `.accessory`;最小化仍保留 Dock 图标;点击 Dock 图标走 `applicationShouldHandleReopen` 重新打开主面板。已通过 System Events 实测 `background only` 在打开/关闭时分别为 false/true。

### 期货
详见「开发进度.md」第五节(数据来源、标识、高可用、调度、限制)。

要点:
- 数据取法:国内与外盘行情、分时、搜索均走东财 `push2`/`push2his`/`searchapi`;新浪 `nf_`(国内)、`hf_`(外盘)、`znb_`(全球指数)作行情备源,新浪 `getMinLine` 作国内分时备源。
- 放置位置:默认「期货」分组,与自选股同等使用(侧栏、Popover、悬浮窗、菜单栏固定)。
- 分时横轴抽象为 `MinuteAxis`(多时段拼接),A 股 240 分钟,期货含夜盘跨零点。
