# 在线更新与自动发版

> @author ixxxxoooo

## 需求
1. CI/CD:推送版本标签后自动构建、打包并发布到 GitHub Release。
2. 在线更新:检测 GitHub 新版本并支持在线更新(热更新),调研方案并测试成功后交付。

## 方案
- 不引入 Sparkle,自实现:GitHub API(失败回退网页重定向)→ 下载 zip 并校验 SHA-256 → ditto 解压并校验 Bundle ID / 版本 / codesign → 独立安装脚本原子替换并重启,失败回滚。
- 沙盒应用无法替换自身 .app,故关闭沙盒;自选库显式放到 Application Support/StockMenuBar。
- 原生应用不能热补丁运行中的代码,"热更新"实现为无人工干预的下载 + 替换 + 自动重启。
- 发版:`.github/workflows/release.yml` + `scripts/package.sh`(通用二进制,ad-hoc 签名)+ `scripts/release_notes.sh`。

## 验证
单元测试覆盖下载/校验/篡改/替换/回滚/状态机;端到端用本地服务器模拟新版本,命令行与界面点击两条路径均更新成功。
